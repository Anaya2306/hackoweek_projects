📋 Step-by-Step Process

Step 1: Input Reception Student enters a natural language query without worrying about specific keywords or formats.
Step 2: Entity Extraction System extracts three types of entities:
  • Course Codes: Regex pattern matching (e.g., CSE101, CSE501)
  • Semester Numbers: Matches "sem X" or "semester X" (where X is 1-8)
  • Dates: Matches date formats like 15/01/2026 or "January 15"
Step 3: Keyword-Based Course Recognition If no course codes found, system searches for course-related keywords:
"Tell me about AI" → Matches keyword "AI" → Finds CSE501 & CSE502
"Database course" → Matches keyword "database" → Finds CSE202
"Mobile development" → Matches keyword "mobile" → Finds CSE701
Step 4: Intent Detection System identifies what the student is asking for:
  • exam_info: Questions about exam dates
  • course_info: Questions about available courses
  • schedule: Questions about full schedules
  • help: Study help requests
  • upcoming: Upcoming events
Step 5: Database Lookup Course database contains:
Semester 1: CSE101, CSE102
Semester 2: CSE201, CSE202
... (continues through Semester 8)
Total: 16 CSE courses with exam dates
Step 6: Response Generation System generates intelligent response based on:
  • Detected intent
  • Extracted entities (courses, semesters, dates)
  • Database information
Step 7: Display Results Results shown in three sections:
  • 🎓 Semesters: Extracted semester numbers
  • 💻 Course Codes: Found course codes
  • 📅 Dates: Extracted dates
  • 💬 Response: Contextual answer from system
